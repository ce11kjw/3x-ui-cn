# 3X-UI 中文版

基于 [MHSanaei/3x-ui](https://github.com/MHSanaei/3x-ui) 官方脚本纯翻译，不修改任何代码逻辑。

## 一键安装（中文版）
```bash
bash <(curl -Ls https://raw.githubusercontent.com/ce11kjw/3x-ui-cn/main/install.sh)
```

## 中文管理脚本
安装完成后，如需将管理菜单替换为中文版：
```bash
bash <(curl -Ls https://raw.githubusercontent.com/ce11kjw/3x-ui-cn/main/x-ui.sh)
```
选择 2（更新菜单）即可将 `x-ui` 命令替换为中文版。
