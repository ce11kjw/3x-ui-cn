# 3X-UI 中文版

基于 [MHSanaei/3x-ui](https://github.com/MHSanaei/3x-ui) 官方脚本纯翻译，不修改任何代码逻辑。

---

## 一键安装（中文版安装脚本）

```bash
bash <(curl -Ls https://raw.githubusercontent.com/ce11kjw/3x-ui-cn/main/install.sh)
```

## 一键重新部署

如果需要完全重新部署（卸载旧版+安装中文版），运行：
```bash
bash <(curl -Ls https://raw.githubusercontent.com/ce11kjw/3x-ui-cn/main/redeploy.sh)
```
此脚本会：停止旧服务 → 卸载旧版 → 安装中文版 → 替换管理菜单为中文

---

## 替换管理菜单为中文版

安装完成后，运行以下命令将 `x-ui` 管理菜单替换为中文：

```bash
curl -sL https://raw.githubusercontent.com/ce11kjw/3x-ui-cn/main/x-ui.sh -o /usr/bin/x-ui && chmod +x /usr/bin/x-ui
```

> ⚠️ 每次更新 3x-ui 后需要重新执行上面的替换命令。

### 0. 退出脚本

直接退出管理脚本，不做任何操作。

---

### 1. 安装

首次安装 3X-UI 面板。安装过程中会让你设置：
- **数据库类型**：SQLite（默认，推荐）或 PostgreSQL
- **面板端口**：可以自定义或随机生成
- **登录用户名和密码**：随机生成，安装完成后显示
- **SSL证书**：可以选择 Let's Encrypt 域名证书、IP证书、自定义证书或跳过

安装完成后会集中显示面板信息（用户名、密码、端口、访问地址）。

---

### 2. 更新

将 3X-UI 更新到最新稳定版。**数据不会丢失**。

---

### 3. 更新到开发版（最新提交）

安装最新开发版（每次提交都会更新）。**非稳定版**，可能有bug，但能用到最新功能。数据会保留。

---

### 4. 更新菜单

更新 `x-ui` 命令的管理脚本本身（不更新面板程序）。

---

### 5. 旧版本

安装指定版本的 3X-UI（如 2.4.0）。输入版本号后自动下载安装。

---

### 6. 卸载

完全卸载 3X-UI 和 Xray。会删除所有配置和数据，**不可恢复**。

---

### 7. 重置用户名和密码

重新设置面板的登录用户名和密码。
- 直接回车 = 使用随机生成的用户名/密码
- 输入内容 = 使用你指定的用户名/密码
- 会询问是否同时禁用两步验证（2FA）

**忘记密码时用这个功能。**

---

### 8. 重置Web基本路径

重置面板的 Web 基本路径（URL 中 `端口/` 后面的那串随机字符）。
- 重置后旧的访问地址会失效
- 新地址会在重置后显示

---

### 9. 重置设置

将面板所有设置恢复为默认值。**账号数据不会丢失**，用户名和密码不会改变。

---

### 10. 修改端口

修改面板的访问端口。
- 输入新端口号（1-65535）
- 修改后需要重启面板
- 记得在防火墙/安全组中放行新端口

**例：** 将端口从 `54321` 改为 `2053`

---

### 11. 查看当前设置

显示面板的当前配置信息，包括：
- 用户名、密码
- 端口、Web基本路径
- 数据库类型（SQLite/PostgreSQL）
- SSL证书状态

---

### 12. 启动

启动 3X-UI 面板服务。如果面板已经在运行，会提示无需重复启动。

---

### 13. 停止

停止 3X-UI 面板服务。停止后面板无法通过浏览器访问。

---

### 14. 重启

重启 3X-UI 面板服务。**修改端口、重置密码等操作后需要重启。**

---

### 15. 重启Xray

仅重启 Xray 核心（不重启面板）。用于 Xray 配置变更后生效。

---

### 16. 查看状态

显示面板和 Xray 的运行状态，包括：
- 面板是否运行
- Xray 是否运行
- 监听端口
- mtproto 入站状态（如果有配置）

---

### 17. 日志管理

查看面板和 Xray 的日志。
- **调试日志**：详细的运行日志，用于排查问题
- **清除所有日志**：清空日志文件

**面板出问题时先看日志。**

---

### 18. 启用开机自启

设置面板服务在服务器重启后自动启动。

---

### 19. 禁用开机自启

取消面板服务的开机自启。服务器重启后面板不会自动运行，需要手动启动。

---

### 20. SSL证书管理

管理 Let's Encrypt SSL 证书。子菜单选项：

| 选项 | 功能 |
|------|------|
| 1. 获取SSL（域名） | 为域名申请 Let's Encrypt 证书（90天有效，自动续期） |
| 2. 吊销并移除 | 吊销已有的 SSL 证书并删除 |
| 3. 强制续期 | 强制重新签发 SSL 证书 |
| 4. 显示已有域名 | 查看当前已签发的域名证书列表 |
| 5. 设置面板证书路径 | 手动指定面板使用的证书文件路径 |
| 6. 获取SSL（IP地址） | 为 IP 地址申请证书（6天有效，自动续期） |

**域名证书申请步骤：**
1. 确保域名已解析到服务器 IP
2. 确保 80 端口开放
3. 输入域名
4. 选择验证端口（默认 80）
5. 等待签发完成
6. 选择是否将证书应用到面板

---

### 21. Cloudflare SSL证书

通过 Cloudflare DNS 验证申请 SSL 证书。适合域名在 Cloudflare 上管理的情况。

**使用说明：**
1. 需要 Cloudflare API Token（推荐）或全局 API Key + 邮箱
2. 输入域名
3. 证书签发后会提示是否应用到面板
4. 安装后支持自动续期

**获取 Cloudflare API Token：**
1. 登录 Cloudflare Dashboard
2. 进入 My Profile → API Tokens
3. 创建 Token，权限选择 `Zone:DNS:Edit`
4. 选择对应的 Zone（域名）

---

### 22. IP限制管理

通过 Fail2ban 限制单个用户的连接数。子菜单：

| 选项 | 功能 |
|------|------|
| 1. 安装Fail2ban并配置IP限制 | 首次使用时安装 |
| 2. 修改封禁时长 | 设置违规后封禁的分钟数（默认30分钟） |
| 3. 解封所有人 | 解除所有被封禁的 IP |
| 4. 封禁日志 | 查看被封禁的 IP 列表 |
| 5. 封禁IP地址 | 手动封禁指定 IP |
| 6. 解封IP地址 | 手动解封指定 IP |
| 7. 实时日志 | 实时查看 Fail2ban 日志 |
| 8. 服务状态 | 查看 Fail2ban 服务是否运行 |
| 9. 重启服务 | 重启 Fail2ban 服务 |
| 10. 卸载Fail2ban和IP限制 | 完全卸载 |

---

### 23. 防火墙管理

管理服务器防火墙（ufw/firewalld）。子菜单：

| 选项 | 功能 |
|------|------|
| 1. 安装防火墙 | 安装 ufw（Ubuntu/Debian）或 firewalld（CentOS） |
| 2. 端口列表 | 显示当前已开放的端口 |
| 3. 开放端口 | 开放指定端口（如 80,443,2053） |
| 4. 从列表删除端口 | 关闭指定端口 |
| 5. 启用防火墙 | 开启防火墙 |
| 6. 禁用防火墙 | 关闭防火墙（不推荐） |
| 7. 防火墙状态 | 查看防火墙当前状态 |

**常见端口：**
- `80`：HTTP
- `443`：HTTPS
- `2053`：面板端口（根据你的设置）
- `54321`：自定义端口

### 24. SSH端口转发管理

配置 SSH 端口转发，用于在面板没有 SSL 证书时安全访问。

**使用方法：**
1. 在本地电脑执行 SSH 命令建立隧道
2. 通过 `localhost:2222` 访问面板

**示例：**
```bash
ssh -L 2222:127.0.0.1:54321 root@你的服务器IP
```
然后浏览器打开 `http://localhost:2222`

| 1. 安装PostgreSQL | 安装 PostgreSQL 服务器+客户端+xui数据库 |
| 2. 迁移SQLite→PostgreSQL | 将现有 SQLite 数据迁移到 PostgreSQL |
| 3. 状态 | 查看 PostgreSQL 集群状态和端口 |
| 4. 启动PostgreSQL | 启动数据库服务 |

| 6. 重启PostgreSQL | 重启数据库服务 |
| 7. 启用开机自启 | 设置 PostgreSQL 开机自启 |
| 8. 查看日志 | 查看 PostgreSQL 日志 |

**什么时候用 PostgreSQL？**

- 多节点管理
- 需要更高性能

## 常见问题

### Q: 忘记密码怎么办？
选 `7. 重置用户名和密码`，设置新的用户名和密码。

### Q: 面板打不开？
1. 检查面板是否运行：选 `16. 查看状态`
2. 检查端口是否开放：选 `23. 防火墙管理` → `3. 开放端口`
3. 查看日志排查：选 `17. 日志管理` → `调试日志`

### Q: 如何配置节点？
面板 Web 界面中操作：
1. 登录面板
2. 左侧菜单 → 入站列表
3. 点击 `+` 添加入站
4. 选择协议（推荐 VLESS + Reality）
5. 填写配置参数
6. 保存后复制节点链接

### Q: 如何更新到最新版？
选 `2. 更新`（稳定版）或 `3. 更新到开发版`（最新功能）。
